1. Close the Windows Daily-Driver DealbreakersPower users will test Halo for 10 minutes and uninstall if core Windows workflows break silently. Audit these before public launch:Third-party system tray & IME: Hiding the taskbar hides tray icons (VPNs, Discord, OBS, Steam, NVIDIA, keyboard layout switchers). Even a minimal collapsible tray-overflow chevron in the dock or Control Center removes the #1 reason people abandon Windows docks.Fullscreen game and video suppression: A 2 px bottom catch strip will constantly trigger when scrubbing YouTube timelines or moving the mouse in borderless-windowed games. Detect fullscreen/borderless occlusion (SHQueryUserNotificationState or foreground window matching monitor bounds) and require either a double-bump, a hold duration (e.g., 250 ms), or full suppression on that monitor.Mixed-DPI multi-monitor transitions: A single cursor-following dock is smart, but moving between a 150% laptop panel and a 100% external monitor breaks naive Win32/Composition sizing. Verify per-monitor DPI v2 awareness so icons, hit rects, and blur bounds never rescale weirdly mid-hop.App grouping, progress, and badges: UWP apps, PWAs, and Electron apps frequently mismatch AppUserModelID, causing duplicate dock icons or low-res fallback icons. Adding subtle Windows taskbar signals—a thin progress pill for downloads/file copies and a pulse or dot color shift for FLASHW attention requests—makes Halo feel like a real OS shell rather than an overlay.Keyboard muscle memory: Map Win+1 through Win+9 to Halo's pinned dock order, and support dragging dock icons to reorder or dragging a file onto a dock icon to open it.2. Eliminate First-Run Panic and SmartScreen FrictionShell replacements ask for huge user trust. Strangers will not run a random PowerShell script that hides their taskbar without guardrails.Add a "Display Settings" confirmation guard on first launch: When Halo hides the taskbar for the first time, show a small floating confirmation card with a 15-second auto-revert countdown (plus the Win+Alt+T and Ctrl+Win+Esc hints). If something looks broken on their monitor setup, doing nothing restores Windows automatically.Solve Windows Defender SmartScreen: Unsigned C++ executables that manipulate Shell_TrayWnd get flagged immediately. Apply for free open-source code signing through SignPath Foundation, and build all release binaries publicly via GitHub Actions so users can verify hashes against CI rather than trusting local builds.Ship a real install/uninstall path: Keep tools/build.sh for contributors, but give users a clean installer (Inno Setup or MSIX) + a Winget manifest (winget install ...) and an explicit uninstaller that cleanly removes startup entries and runs guardian.exe --restore.De-friction the Genie mod: Right now, one of your flashiest visual features (halo-genie.wh.cpp) requires Windhawk. Inside halo-settings.exe, detect whether Windhawk and the mod are installed, display a clear status badge, and provide a one-click "Copy mod / Open Windhawk setup" flow instead of silently omitting genie.3. Unify the Product Surface (Retire "HALO 2.0")Shipping two competing layouts behind a version-numbered toggle (HALO 2.0) reads like a work-in-progress branch rather than a cohesive product.Rename by layout intent, not version: Make the stronger layout the default, and frame the toggle functionally (e.g., Start Layout: Compact vs. Dashboard, Dock: Classic vs. Media + Controls).Rethink the 61-quote widget: Hardcoded quotes repeat every two months and slightly undercut the restrained, Apple-grade aesthetic you built with the 4 px grid and shared color tokens. Either turn it off by default or replace that slot with high-utility local info (next calendar item, active timer, or quick power/audio status).Polish halo-settings.exe to match the shell: Users judge a UI product by its Preferences window. Give it the same frosted tokens, clean section sidebar, and live inline feedback (e.g., hovering a mini preview or nudging the actual dock as you drag magnification/speed/tint sliders), plus a Reset to Defaults button and Export/Import settings.ini for sharing themes.4. Push Visual & Motion Polish from 90% to 99%Your compositor details (no whole-panel scaling, 30 px slider hit targets, concentric radii, 64-row genie with zero-blink restore) are already well above average. Four subtle details will make it feel genuinely uncanny:Glass depth in dark mode: On top of your #0B0B0D 78% backdrop and outer hairline, add a 1 px brighter top inner specular rim (rgba(255,255,255,0.12) fading down) and a subtle micro-noise overlay. Without those, Windows acrylic panels tend to look flat or band over solid wallpapers.Interruptible spring reversals: Your reveal uses a spring (0.72 damping, 55 ms period), while hide uses a fixed 200 ms curve. If a user flicks the cursor away and back mid-hide, switching between timed and spring animations can stutter. Running both reveal and hide on retargetable SpringScalarNaturalMotionAnimation (critically damped ~1.0 for hide, 0.72 for reveal) keeps velocity continuous under fast cursor flicks.Hover-intent on DWM thumbnails: Add a slight hover-intent delay (120–180 ms) before opening live window previews—while keeping label hover instant—so sweeping across the dock doesn't flash thumbnail popups. Once one preview is open, switch between adjacent apps instantaneously (0 ms delay).Dynamic light/dark wallpaper contrast: If a user sets light glass over a pure-white maximized browser window, even a 28 px shadow can soften the edge. Slightly bumping the hairline contrast when maximized windows sit behind the dock keeps the silhouette crisp.5.
